# Stackflow modding API

> Generated by `tools/generate_api.py` from the game's doc comments. Do not edit by hand.

Autoloads (`BlockRegistry`, `GameManager`, `GameData`, `AudioManager`, `Random`) are global:
call them directly, e.g. `GameManager.add_points(10)`. Use `Random` instead of `randi()`/`randf()`
so runs stay reproducible from their seed.

## BaseBlock
*Inherits `RefCounted`*

Code-driven definition of a block type (one instance per type). Core and mods use the SAME API: creating a BaseBlock registers it in the BlockRegistry, and the fluent setters wire its effects. No core file needs editing to add new content. Name and description come from the translation keys `BLOCK_<ID>` and `BLOCK_<ID>_DESCRIPTION` (id upper-cased, see GameData.get_block_name).

Example:

```gdscript
BaseBlock.new(&"mymod.rainbow", [GameData.BlockGroups.CASINO], 3, 5) \
    .set_destroy_effect(func(ctx: DestroyEffectContext) -> void:
        GameManager.add_points(10)
    )
```


### Methods

#### `new`
```gdscript
BaseBlock.new(p_id: StringName, p_groups: GameData.BlockGroups[], p_min: int, p_max: int, p_recipe: StringName[] = [], p_price: int = 0, p_unlock: int = 0)
```
Creating a BaseBlock auto-registers it in the BlockRegistry -- core and mods only need to instantiate. set_destroy_effect() mutates the same already-registered instance (the registry holds the reference), so it can be called afterwards via chaining.

#### `set_complexity`
```gdscript
func set_complexity(value: int) -> BaseBlock
```
Returns self for fluent chaining.

#### `set_destroy_effect`
```gdscript
func set_destroy_effect(cb: Callable) -> BaseBlock
```
Returns self to allow fluent chaining during construction.

#### `get_destroy_effect`
```gdscript
func get_destroy_effect() -> Callable
```
The current destroy effect, so a mod can wrap a vanilla block's effect instead of replacing it: keep the old Callable, call it inside the new one.

#### `set_on_place`
```gdscript
func set_on_place(cb: Callable) -> BaseBlock
```
Returns self for fluent chaining.

#### `set_on_block_destroyed`
```gdscript
func set_on_block_destroyed(cb: Callable) -> BaseBlock
```
Returns self for fluent chaining.

### Properties

| Name | Type | Description |
|---|---|---|
| `id` | `StringName` | Unique block id. Mods namespace it ("mymod.ruby") to avoid collisions. |
| `groups` | `GameData.BlockGroups[]` | Synergy groups. Blocks with more than one group are only offered once the deck has a block from one of them. |
| `min_amount` | `int` | How many blocks of this type a piece bought in the Block Selection contains (min..max). |
| `max_amount` | `int` |  |
| `recipe` | `StringName[]` | Unlock requirement in the Block Reward (NOT crafting). The block only enters the roll once the player already owns AT LEAST ONE of these ids in the original deck (logical OR). Empty => no requirement. See GameManager reward eligibility. |
| `price` | `int` | Cost in credits to acquire the block in the Block Selection screen. Scaled by purchases via GameManager.get_block_price. |
| `unlock_round` | `int` | First round in which the block can be offered (0 = from the start). |
| `complexity` | `int` | How hard the block is to understand/use: 1 simple, 2 medium, 3 complex. Not a gate: it lowers the block's chance on the Block Selection early in the run, ramping to full weight by GameData.MID_GAME_ROUND. See GameManager._compute_block_weight. |
| `texture_path` | `String` | Path to the texture. Empty => resolved by convention via get_block_texture_path. Mods point at a PNG in their own folder; raw (non-imported) PNGs load through GameData.load_texture. |

## DestroyEffectContext
*Inherits `RefCounted`*

Context passed to a BaseBlock's destroy-effect Callable. Deliberately kept minimal: block-specific fields do NOT become properties here (would not scale to 40+ blocks). Data derivable from the block itself is computed by the effect (e.g. neighbour count via block.get_adjacent_blocks_of_type). Data only the orchestrator knows (chain reward, morph target) arrives through `payload`, a Dictionary of named keys -- allows multiple values without bloating the context.

### Methods

#### `new`
```gdscript
DestroyEffectContext.new(p_block: PlacedBlock, p_payload: Dictionary = {})
```

### Properties

| Name | Type | Description |
|---|---|---|
| `block` | `PlacedBlock` | Block being destroyed. Always present. |
| `payload` | `Dictionary` | Block-specific payload from whoever triggers the effect. Keys depend on the block: - vine/mushroom: { "reward": int }  (reward from the position in the chain) - bookshelf:     { "morph_target": StringName } Use payload.get(key, default) in the effect. Default {} => blocks that don't need it ignore it. |

## BlockRegistry
*Inherits `Node`*

Central registry of block types (autoload). Replaces the lookups scattered across GameData (`blocks`, is_valid_block_type, is_block_on_group) with a single source. Core and mods register via register(); ModLoader calls the mods' register_blocks() after the core has populated the base blocks.

Lookups accept String and StringName: coerced to StringName internally, so the ~120 call sites passing String (block_type) keep working without conversion.

### Methods

#### `register`
```gdscript
func register(block: BaseBlock) -> void
```

#### `get_block`
```gdscript
func get_block(id: String) -> BaseBlock
```

#### `has_block`
```gdscript
func has_block(id: String) -> bool
```

#### `is_valid`
```gdscript
func is_valid(id: String) -> bool
```
Semantic alias of has_block (single source for block-type validation).

#### `block_in_group`
```gdscript
func block_in_group(id: String, group: GameData.BlockGroups) -> bool
```
Replaces GameData.is_block_on_group. Cached. Unknown ids => false. Name can't be is_in_group -- collides with Node.is_in_group(StringName).

#### `all_ids`
```gdscript
func all_ids() -> String[]
```

### Properties

| Name | Type | Description |
|---|---|---|
| `core_blocks_ready` | `bool` | True after CoreBlocks has emitted blocks_ready. Mods that connect late can check this and call their registration immediately if it has already fired. |

### Signals

- **`blocks_ready()`** Emitted after CoreBlocks finishes registering all base blocks. Mods should connect to this signal (instead of registering in _init/_ready directly) to guarantee the core blocks already exist -- allowing them to safely override/extend base blocks. See CoreBlocks.register_blocks().

## PlacedBlock
*Inherits `Node2D`*

### Methods

#### `get_center_position`
```gdscript
func get_center_position() -> Vector2
```
Global position of the block's center. Use it to spawn a PointNotification over the block.

#### `morph`
```gdscript
func morph(new_type: String) -> void
```
Turns this block into another type in place (texture and GameManager bookkeeping included). Indestructible blocks never morph.

#### `pulse_animation`
```gdscript
func pulse_animation(flash_animation_enabled: bool = true) -> void
```
Bounce (and optionally flash) the block: visual feedback when it reacts to something.

#### `get_adjacent_blocks`
```gdscript
func get_adjacent_blocks(include_diagonals: bool = false) -> PlacedBlock[]
```
Orthogonal neighbors (Manhattan <= 1). With `include_diagonals`, the 8 surrounding blocks (Chebyshev <= 1), used by the Swarm and Blast Radius perks.

#### `get_adjacent_blocks_of_type`
```gdscript
func get_adjacent_blocks_of_type(block_type: String, include_diagonals: bool = false) -> PlacedBlock[]
```
Like get_adjacent_blocks, filtered to one block id.

#### `get_blocks_in_range`
```gdscript
func get_blocks_in_range(search_range: int) -> PlacedBlock[]
```
Every block within `search_range` cells (Manhattan distance), excluding itself.

#### `get_blocks_in_range_of_type`
```gdscript
func get_blocks_in_range_of_type(search_range: int, block_type: String) -> PlacedBlock[]
```
Like get_blocks_in_range, filtered to one block id.

#### `collect_connected_chain`
```gdscript
func collect_connected_chain(block_type: String) -> PlacedBlock[]
```
Collects the whole chain of same-type blocks connected to this one (transitive flood-fill, Chebyshev <= 1), excluding itself. Returned in proximity order (BFS), so the scaling reward grows from the center outward.

#### `get_connected_chain_neighbors`
```gdscript
func get_connected_chain_neighbors(block_type: String) -> PlacedBlock[]
```
Same-type neighbours touching this block (Chebyshev <= 1). Base of the transitive flood-fill.

#### `destroy`
```gdscript
func destroy() -> void
```
Destroys the block and runs its destroy effect, as a line clear does. Indestructible blocks ignore it.

### Properties

| Name | Type | Description |
|---|---|---|
| `type` | `String` | Block id (e.g. "iron", "mymod.ruby"). Setting it runs the block's on_place callback. |
| `grid_position` | `Vector2i` | Cell on the board (x = column, y = row, row 0 at the top). |
| `destroy_animation_requested` | `bool` | True once the block started being destroyed. Timers created in on_place should stop when it turns true. |
| `custom_variables` | `Dictionary` | Free per-instance storage for block effects (counters, flags). Namespace mod keys, e.g. "mymod.charge". |
| `activation_count` | `int` | How many times chain reactions (projectiles, explosions) activated this block. |

### Signals

- **`destroyed()`**

## GameManager
*Inherits `Node`*

### Methods

#### `add_points`
```gdscript
func add_points(value: Variant) -> void
```
Adds to the points of the current line clear (blue in the UI). Accepts int, float or Big.

#### `add_multiplier`
```gdscript
func add_multiplier(value: Variant) -> void
```
Adds to the multiplier of the current line clear (red in the UI). Accepts int, float or Big.

#### `is_game_busy`
```gdscript
func is_game_busy() -> bool
```
Returns true if the game is currently busy with calculations, animations, or event processing. Use this to prevent actions like Uranium morphing during non-playable states.

#### `get_blocks_of_type`
```gdscript
func get_blocks_of_type(block_type: String) -> PlacedBlock[]
```
Every block of this id currently on the board.

#### `get_blocks_of_group`
```gdscript
func get_blocks_of_group(block_group: GameData.BlockGroups) -> PlacedBlock[]
```
Every block of this group currently on the board.

#### `has_block_type_in_original_deck`
```gdscript
func has_block_type_in_original_deck(block_type: String) -> bool
```
True if the player's deck (not the board) contains this block id.

#### `add_credits`
```gdscript
func add_credits(amount: Variant) -> void
```
Adds credits (the shop currency) to the balance. Accepts int or Big.

### Properties

| Name | Type | Description |
|---|---|---|
| `timescale` | `float` | Game speed multiplier. Divide Timer/Tween durations by it so effects follow fast-forward. |
| `current_round` | `int` | Current round of the run, starting at 1. |

### Signals

- **`points_changed(value: Big)`**
- **`multiplier_changed(value: Big)`**
- **`piece_landed(blocks: PlacedBlock[], rotated: bool)`** Emitted after the player's piece is placed, with its blocks.
- **`block_destroyed(block: PlacedBlock)`** Emitted for every destroyed block.

```gdscript

```
Loads (and caches) a texture by path. Imported textures go through load(); a path with no import data (a raw PNG shipped inside a mod zip) is decoded with Image.load_from_file, so modders don't need the Godot editor to import their art.

Texture path of a block: its BaseBlock.texture_path when set (mods point at their own folder), otherwise the `res://images/blocks/<id>.png` convention.
